# github

1. 根据待回答问题定位官方仓库，核对 owner/repository、上游和 fork 的关系。
2. 固定 tag、commit 或分支当前 SHA；阅读相关源码、配置、测试及提交，保留精确文件和行/符号定位。
3. 核对 issue/PR/release 的状态和时间。区分讨论、未合并提案、已合并代码与已发布版本。
4. 使用 Host 已提供且授权的查询工具实际读取来源。缺凭据、网络或工具时报告缺口，不把链接回显当作读取证据。
5. 输出来源 URL、ref/commit、支持的主张、适用版本和限制。未经明确授权不提交 issue、评论、PR 或仓库写入。

## 工具与权限

仅使用当前 Host 授予的工具。Skill 描述工作方法，不授予会议身份、写权限或额外网络权限；读取本文件不执行脚本。
