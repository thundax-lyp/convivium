# arxiv

1. 用问题和主题定位论文，核对 arXiv ID、标题、作者、提交日期和明确版本号。
2. 实际读取摘要及与主张相关的正文、图表和附录；只读摘要时明确限制，不声称核验过全文。
3. 提取方法、数据集、基线、评价指标、实验设置和结果，区分作者主张与实验支持范围。
4. 检查消融、反例、样本与外推限制；版本变化时比较相关内容，不能混用不同版本数据。
5. 输出 arXiv ID/version、可定位的 PDF/页面 URL、结论、证据和局限。论文证据不能覆盖仓库事实、正式需求或用户决定。
