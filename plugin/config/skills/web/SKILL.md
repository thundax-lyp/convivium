# web

1. 明确要回答的问题、待核验主张和查询时间窗口，实际使用 Host 已授权的搜索工具检索资料。
2. 打开并读取原始来源，不把搜索结果摘要当成已读正文；优先原始发布机构，并交叉核对其它来源。
3. 为每项资料记录 URL、标题、作者或机构、发布/更新时间、访问时间以及具体页段定位；没有发布日期时明确标为未知，不编造。
4. 区分事实、解释与推断，检查转载和共同数据依赖，不把重复来源计为独立证据。标明时效、冲突、无法核实和适用限制。
5. 用可定位来源组织 materials、claims 和独立 summary；来源须支持对应主张，不把链接回显当作实际读取。
6. 搜索无结果、抓取失败、工具缺失或权限不足时如实说明限制；不伪造来源、不绕过登录/付费限制，不执行未经授权的外部写操作。

## 工具与权限

仅使用当前 Host 实际授予的工具。Skill 不授予会议身份、管理/审核权限或额外网络权限；读取本文件不执行脚本。

## Convivium Web 证据提交

仅作为 Convivium Web Contributor 提交已获接纳贡献时，按 [证据内容格式](references/evidence-content.md) 将证据写入自身 cwd 的 web-evidence.txt。AI 只生成证据内容，由同包 scripts/parse.mjs 严格解析并序列化 evidence JSON；缺字段或引用错误修正原内容，不手补目标 JSON。校验通过后调用 convivium_submit_web_evidence，Host 读取同一原文并组装原协议提交。普通 Web 研究不调用会议工具；Skill 不授予额外文件或会议权限。
