# evidence-review

1. 固定待审材料的不可变版本，逐项列出需要核实的主张与对应来源，不能用别的版本结果替代。
2. 直接检查来源和方法，核对输入、前提、样本、命令或实验设置；区分观察、推断与作者主张。
3. 寻找能够推翻结论的反例，检查权限、失败、并发、恢复及边界条件中与主张有关的部分。
4. 检查证据是否真正支持结论，指出缺失依据、可复现性问题、适用范围和不确定性。
5. 返回逐主张判断和来源定位；未执行的验证明确写未验证。审核方法不赋予业务接受、发布或风险处置权限。
