# meeting-facilitation

1. 读取当前议题、必要产出、验收条件、硬约束与剩余预算，区分已提交事实和待验证主张。
2. 对照参与者职责、现有证据、未解决问题与阻塞，指出本轮需要回答的具体问题及证据缺口。
3. 形成有限计划：预期产出、依据、承担者、必要复核和停止条件。避免重复已有证据；独立交叉验证须说明理由。
4. 讨论偏离、重复或长期无进展时，围绕原目标收敛；新议题只记录为候选，不自动替换目标。
5. 依据已公开结果说明满足了什么、还缺什么。不以发言数量、自然语言赞同或计划代替验收事实。
