# repository-analysis

1. 确认目标仓库和精确 ref/commit，读取适用工程规则、正式需求与接口，明确待验证主张和反例。
2. 从真实入口追踪输入、调用、状态、权限、持久化和输出。优先查源码与配置，不仅引用 README。
3. 核对相关测试、提交记录和可复现命令；区分目标设计、当前实现、测试替身证明与真实运行证据。
4. 只运行授权范围内能检验主张的最小验证，记录命令、环境、结果和未覆盖边界；未经授权不改代码或数据。
5. 输出文件/symbol/ref 定位、结论依据、失败条件、影响和最小修正建议。不从测试通过推断未运行的外部链路可用。
