# Current Implementation Coverage

## Read This First

本文件按已确认的功能点记录当前 checkout 的真实实现状态。状态中的“已有”只表示源码中存在对应的旧能力；除非同时标为“已对齐”，否则不能作为当前 Interface 与 Design 的实现完成证据。

本轮以当前 requirements/interfaces/designs 为依据记录已验证范围。2026-09-17 已确认删除 Manager 私有草稿/FormatApproval、改为唯一专职 reviewer 的 worker 并发与批量提交、使用 identityKey 创建映射、按值归档白名单、确定性消息预算预留、精确 DSH 版本、受限续会素材并删除 Scribe。现有源码与历史验证均早于该口径，除未受影响的纯 Domain 行为和既有身份准入事实外，不得继续标为当前需求已对齐。

## Implementation Gap

目标 `MeetingState` 的大量纯 Domain action 已建立，但 2026-09-17 的确认口径要求先删除私有草稿/FormatApproval、收敛唯一 reviewer、增加 reviewer batch、identityKey 创建映射、消息名额派生、异常 Round、按值 ArchivePackage 和受限 ContinuationMaterial。完成这些最小模型替换后，才可把 Repository 原子提交、幂等、outbox、Session ownership 和归档接到新核心；随后接入 DSH adapter、Remote DTO、Client projection、角色 preflight 与真实运行验证。

旧实现不要求兼容：当前设计没有承诺对 Turn、SpeakerAttempt、旧协议字段或旧归档格式作迁移读取。因此在新切片中保留旧模型会形成双重事实源，应在对应替换完成时删除旧路径，而不是增加适配层。

## Explicitly Not Covered

- 除身份准入切片外，其他新 MeetingState 集成测试、真实 DSH profile、Browser 与真实模型行为未执行；身份准入 smoke 仅证明 RUNBOOK 固定的两条 Host 场景，不代表全产品运行覆盖。
- 旧 smoke 或 operations 文档中的历史通过记录，仅说明旧基线曾运行；不能证明本文件列出的目标实现。
- PrivateMail 的 idempotency、atomic commit、Session delivery、Remote/Client visibility、restart/recovery、真实 DSH/Browser 未验证；Runtime、Repository、outbox、真实 delivery、projection 与 recovery 仍未覆盖。
- Decision/Risk/Completion 仅声明纯 Domain 行为已覆盖；Repository/runtime、真实 DSH/Browser 与终止/archive 外围仍未覆盖。
- 2026-09-17 的 evidence/reviewer/create/archive/continuation/message-budget/role-resource 口径尚无实现或验证；历史 format approval、九角色和单 Review 测试不构成新口径证据。
- 自动 research freshness/source-scope 去重是必要后续能力，但 V1 明确不实现；当前只承诺同 candidateId + agendaId 的 provisioning/active 去重。
- 性能、并发压力、迁移、旧数据兼容、远端文件系统和发布均不在当前阶段承诺中。
