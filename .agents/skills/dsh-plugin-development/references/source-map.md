# rc.2 真相源映射

本映射固定到 `dsh-v0.1.1-rc.2`，只用于维护 reference 或核对依据。先确认 checkout 精确命中该 tag，再读取下列 repository path。事实冲突按公开类型与运行时代码、执行中的 gate、行为测试、所属包 README、其他叙述文档的顺序裁决；示例代码必须同时满足类型和行为来源，不能只从叙述段落推导。

这里的文件级映射用于定位证据，不表示每个来源都实现了 reference 中的全部建议。维护正文时明确区分“rc.2 已实现”“仓库规则要求”“由现有 primitive 推导”和“仅在外部协议要求时适用”；无法归入其中之一的绝对措辞不得保留。
